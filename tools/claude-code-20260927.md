# Claude Code

Claude Code é a ferramenta de linha de comando da Anthropic para programação assistida por IA. O vídeo mostra dois engenheiros da própria empresa usando o produto durante 24 minutos — e o autor do tweet admite que usava o Claude Code "como um mono", ou seja, no automático, sem extrair o que a ferramenta realmente entrega.

## Por que importa

A diferença não está em digitar prompts melhores. Está em entender o fluxo de trabalho: como os engenheiros quebram tarefas grandes em etapas, como usam o contexto do repositório, como revisam e iteram sobre o código gerado. Quem usa a ferramenta como um autocomplete glorificado perde a parte que importa — a colaboração ativa entre dev e IA. O vídeo é um exemplo prático de como profissionais que conhecem a ferramenta por dentro trabalham no dia a dia.

## Como começar

Assista ao vídeo inteiro, sem pular. Preste atenção em três coisas:

1. **A ordem das ações** — eles leem o código antes de pedir mudanças? Rodam testes entre iterações?
2. **Como usam o histórico** — voltam em versões anteriores? Como recuperam contexto?
3. **O nível de especificidade** — não pedem "refatore isso", pedem algo mais concreto.

Depois, abra um projeto pequeno seu e tente replicar o fluxo, mesmo que pareça mais lento no começo. O ganho vem da prática, não da ferramenta em si.
