# DESENVOLVEDOR USA IA PARA SE CANDIDATAR A 700 VAGAS E CONSEGUIU EMPREGO

Um desenvolvedor criou um sistema que usa IA para automatizar candidaturas a vagas de emprego. Ele aplicou em mais de 700 vagas e conseguiu uma posição. O código foi disponibilizado como open source. A ferramenta escaneia páginas de carreira de empresas, reescreve o CV para cada vaga e preenche formulários de candidatura.

## Por que importa

O ponto forte é a personalização em escala. O sistema lê os requisitos de cada oferta e ajusta o CV para aquela posição. Com 700 candidaturas, fazer isso manualmente é inviável. O autor lista recursos como 14 modos de habilidade (avaliar, escanear, PDF), painel no terminal, geração de PDF otimizado para ATS via Playwright e mais de 45 empresas pré-configuradas, incluindo Anthropic, OpenAI e Stripe. Isso significa que cada empresa recebe uma versão diferente do CV, sem trabalho manual repetitivo.

A ferramenta não substitui a decisão final, mas reduz o trabalho braçal de candidatura. Para quem está em busca ativa, é um exemplo prático de automação com IA aplicada a um processo real.
