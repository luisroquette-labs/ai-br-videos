# OPENAI NÃO QUER FAZER UM CHATBOT MELHOR. QUER SUBSTITUIR TODO TRABALHO HUMANO

O vídeo não apresenta ferramenta nem repo. Apresenta uma tese direta: a corrida da AGI não é por chatbots melhores. Tristan Harris afirma que OpenAI e outras empresas miram na substituição do trabalho cognitivo humano. Marketing, texto, ilustração, vídeo, código. Tudo que uma pessoa faz com o cérebro.

## Por que importa

Se a tese estiver certa, o produto real não é o assistente que conversa. É o sistema que executa a tarefa inteira, sem humano no meio. Para dev, isso muda prioridade: não basta integrar API de chat. É preciso entender onde o trabalho mental está sendo automatizado — inclusive o seu.

O recado é incômodo: essas empresas não estão melhorando ferramentas para aumentar sua produtividade. Estão construindo substitutos para o seu papel.
