# Blockworks MCP

O Blockworks MCP é um servidor Model Context Protocol que expõe os datasets da Blockworks para agentes de IA. Com ele, ChatGPT, Claude ou qualquer agente compatível com MCP pode consultar esses dados diretamente, sem depender de uma API exclusiva. A ideia é simples: a Blockworks disponibiliza o que tem e o agente consome via protocolo padrão.

## Por que importa

Para dev, o benefício é prático. Você não precisa escrever parser nem manter integração customizada para cada fonte. Configura o servidor MCP e o agente acessa os dados da Blockworks como se fossem uma ferramenta nativa. Isso reduz o atrito para construir agentes com informação financeira estruturada. E sinaliza uma tendência: empresas com dados proprietários estão usando MCP como porta de entrada para agentes, em vez de criar APIs exclusivas.
