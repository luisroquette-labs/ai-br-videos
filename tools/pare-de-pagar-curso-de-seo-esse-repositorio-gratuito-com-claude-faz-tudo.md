# PARE DE PAGAR CURSO DE SEO: ESSE REPOSITÓRIO GRATUITO COM CLAUDE FAZ TUDO

O repositório gratuito resume o que o tweet defende: para que pagar curso de SEO se um modelo como o Claude Opus faz o trabalho pesado? A proposta tem quatro partes — pesquisa de palavras-chave que não inventa volume de busca (problema comum em ferramentas de IA genérica), script de auditoria de site rodado em um comando, briefs construídos a partir do que já está rankeando e um guia para sair citado em AI Overviews e ChatGPT. O princípio é objetivo: o Opus raciocina, mas a fonte de verdade são seus próprios dados, não a alucinação do modelo.

## Por que importa

A maioria das ferramentas de SEO com IA entrega números inventados porque não ancora o modelo em dados reais. Aqui, a auditoria e a pesquisa partem do que já existe no seu site e nos resultados atuais. Isso resolve o problema prático: menos achismo, mais output utilizável para quem precisa publicar e rankear sem depender de curso.

## Como começar

O link está nos replies do tweet original do @cyrilXBT. Acesse, clone o repositório e leia o README antes de executar qualquer script. Prepare seus próprios dados antes — Search Console, analytics ou um crawl do site — porque os scripts dependem desse contexto para o Opus trabalhar com informação confiável.
