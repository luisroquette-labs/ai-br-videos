# Claude Code

O vídeo apresenta um projeto open-source — com mais de 76 mil estrelas — que roteia o Claude Code para 10 provedores de IA gratuitos, incluindo DeepSeek e Kimi. Em vez de pagar pela API oficial, você mantém o mesmo fluxo de trabalho e usa modelos alternativos. O setup, segundo a descrição, leva cerca de 5 minutos.

## Por que importa

Custo de API pesa em uso contínuo. Esse roteador resolve isso sem trocar a interface: você continua no Claude Code, mas por trás a chamada vai para um provedor gratuito. Isso permite rodar automações, testes e projetos pessoais sem estourar orçamento. Também reduz a dependência de um único fornecedor.

## Como começar

O tweet aponta para um repositório com instruções. O processo básico envolve: instalar o roteador, configurar as credenciais dos provedores gratuitos que você quer usar e apontar o Claude Code para ele. A promessa é de configuração em cinco minutos. Comece com um comando simples para validar antes de usar em tarefas reais.
