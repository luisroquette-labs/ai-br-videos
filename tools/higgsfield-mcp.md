# Higgsfield MCP

Higgsfield MCP conecta Claude a uma pipeline de motion graphics. No demo, Claude Opus 5.5 recebeu uma única instrução e orquestrou 12 laptops via Computer Use. Distribuiu o trabalho entre máquinas, gerou os visuais e as animações, e entregou um projeto After Effects editável. Você não fica com um vídeo renderizado. Fica com o arquivo fonte.

## Por que importa

O ponto não é "a IA faz vídeos". É que o resultado é um projeto After Effects editável. Um humano pode abrir, ajustar e finalizar. Isso mantém o controle na pessoa, não na IA. A orquestração entre máquinas também mostra um padrão útil: dividir tarefas paralelas entre computadores, em vez de forçar uma única sessão a fazer tudo. Para pipelines de produção, essa arquitetura escala melhor que um agente monolítico.

## Como começar

O demo assume Claude com Computer Use habilitado. O Higgsfield MCP entra como servidor MCP no seu cliente Claude. O fluxo: descreva o vídeo, deixe Claude distribuir as tarefas e inspecione o projeto After Effects gerado. Não há repo público identificado no material original. Valide a configuração no ambiente onde você já roda MCP.
